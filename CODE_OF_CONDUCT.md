# Code of Conduct

Memento is built by people with different backgrounds, identities, and levels
of experience. We expect everyone participating in the project to make that
collaboration safe, direct, and constructive.

## Expected behavior

- discuss ideas and code without attacking people
- give actionable feedback and accept correction in good faith
- respect privacy, especially when examples involve personal memory stores
- disclose conflicts of interest and security concerns promptly
- help newcomers understand the system instead of gatekeeping it

## Unacceptable behavior

- harassment, threats, discrimination, or sexualized attention
- publishing another person's private information
- deliberately degrading discussions, reviews, issues, or project infrastructure
- using project spaces to promote scams, malware, or unrelated commercial spam

## Enforcement

Report conduct problems privately to [hello@arvor.co](mailto:hello@arvor.co).
Maintainers may edit or remove contributions, comments, or accounts that violate
this policy. Reports will be reviewed with attention to the safety and privacy of
the people involved.

This policy applies in repository spaces and when someone is publicly
representing the Memento project.
